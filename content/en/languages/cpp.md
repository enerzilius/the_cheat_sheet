## Variables

```c++
// Integer types
int number = -10;
unsigned int age = 22;
short shortInt = 6000; // 16 bits
long longInt = 1000000; // 32 bits

// Can be true or false
bool isOverage = age >= 18;

// Floating-point types
float weightKg = 77.8;
double doubleNumber = -9998.0;

char character = 'a';
std::string name = "Anderson Silva"; // needs #include <string>
```
